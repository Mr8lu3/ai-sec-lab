# Cross-Domain Misconfiguration

- **Finding ID:** `zap-e50391e9`
- **Source:** zap
- **Severity:** medium
- **Affected:** http://localhost:3000
- **Evidence:** evidence=Access-Control-Allow-Origin: * | result=The CORS misconfiguration on the web server permits cross-domain read requests from arbitrary third party domains, using unauthenticated APIs on this domain. Web browser implementations do not permit arbitrary third parties to read the response from authenticated APIs, however. This reduces the risk somewhat. This misconfiguration could be used by an attacker to access data that is available in an unauthenticated manner, but which uses some other form of security, such as IP address white-listing.
- **Reproduced:** confirmed - Access-Control-Allow-Origin: * returned

## Description

Cross-Domain Misconfiguration allows any domain to access unauthenticated API responses, reducing security controls.

## Impact

An attacker could access data intended for authenticated users, compromising security.

## Remediation

Restrict Access-Control-Allow-Origin to specific domains or use more secure headers like Access-Control-Allow-Origin: null.
